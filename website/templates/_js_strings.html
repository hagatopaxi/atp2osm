{# The strings the scripts display. A JSON block rather than an inline script: the values go through gettext like any other template string, and `t()` in static/js/i18n.js reads them from here. Keyed by a slug, because a key is not a sentence: rewording the French does not touch the JavaScript. Placeholders are written {name} rather than the gettext %(name)s — gettext formats a string as it hands it over, and would fail on a placeholder it has no value for. #}
